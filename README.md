# quest_app — DEPRECATED

**This repository is deprecated and archived.** It is no longer built, maintained or used.

The standalone Quest headset build has been superseded by the SSStudio line of work. Its crate fails to compile on purpose (see `src/lib.rs`).

The live Space Soup stack is: `ssstudio` (the editor and the app), `game` (scenes, models, logic), `space_soup` (renderer), `space_soup_engine` (runtime), `spacesoup_graphics` (the look), `space_soup_sky`, `entity_core`, `avatar_pose`, `avatar_ik`, `hand_menu_core`, `prop_core`, `space_soup_protocol` and the `wgpu` fork, all on `main`.
